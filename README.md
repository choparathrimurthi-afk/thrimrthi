# Ch. Thrimurthi — 3D AI & ML Personal Portfolio

Interactive 3D personal portfolio website for **Ch. Thrimurthi**, first-year BTech Computer Science and Engineering (AI & ML) student at **Joy University**.

## Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **3D Graphics**: Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Styling & Motion**: Tailwind CSS v4, Motion (`motion/react`), Lucide Icons

## Prerequisites

- **Node.js** `v18.0.0` or newer
- **npm** `v9.0.0` or newer

## Run Locally

1. **Install dependencies**

   ```bash
   npm install
   ```

2. **Start the development server** (runs on port `3000`)

   ```bash
   npm run dev
   ```

   Open `http://localhost:3000` in your browser.

3. **Type-check and build for production**

   ```bash
   npm run lint
   npm run build
   ```

4. **Preview the production build**

   ```bash
   npm run preview
   ```
